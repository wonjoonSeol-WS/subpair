# Subpair: 스토어 등록 정보 (한국어)

스토어 양식에 그대로 붙여 넣으세요. English: [en.md](en.md), 日本語: [ja.md](ja.md).
업로드 파일: `npm run package`가 `dist/packages/subpair-chrome-<버전>.zip`과 `dist/packages/subpair-firefox-<버전>.zip`을 만듭니다.

## 이름
Subpair

## 요약 (Chrome: 132자 이하, AMO: 250자 이하)
Netflix와 Jellyfin에서 자막 두 줄을 함께 보여 줍니다. 대본 패널, 한 줄 다시 듣기, 자동 일시정지, 로컬 번역(선택)을 지원합니다.

## 설명
Subpair는 두 언어의 자막을 함께 보여 주어, 영상을 보면서 언어를 배울 수 있게 합니다. 위에는 배우는 언어,
아래에는 내 언어가 나옵니다.

- Netflix와 내 Jellyfin 서버(웹 플레이어)에서 동작합니다.
- 두 줄 동시 표시: 주 자막과 두 번째 자막을 각각 원하는 언어로, 대체 언어까지 지정할 수 있습니다.
- 내 언어 자막이 없나요? 내 컴퓨터의 작은 프로그램(브리지)으로 주 자막을 번역할 수 있습니다:
  ezTrans, Claude, Anthropic API 또는 OpenAI 호환 서비스. 번역은 작품마다 저장되어 다시 쓰입니다.
- 다음 화를 미리 번역하고, Jellyfin에서는 클릭 한 번으로 시즌 전체를 번역합니다.
- 대본 패널, 이전/반복/다음 줄, 줄이 끝날 때마다 자동 일시정지.
- 단어를 클릭하면 복사되고, 일본어 단어는 품사별 색으로 표시됩니다.
- 영상 위 또는 하단 바, 글자 크기, 간격, 배경: 모두 플레이어 안의 빠른 메뉴에서 바꿉니다.
- 툴바나 Alt+Shift+S로 끄면 사이트 자체 자막이 다시 나옵니다.
- 영어, 한국어, 일본어 인터페이스.

Subpair에는 계정, 분석 도구, 자체 서버가 없습니다. 자막 텍스트는 내 컴퓨터의 브리지로 가고,
그 다음에는 내가 고른 번역기로만 갑니다. Jellyfin에서는 완성된 번역을 내 Jellyfin 서버에도 자막 트랙으로 저장해
(그 언어 자막이 없는 작품만) TV와 휴대폰 앱에서도 볼 수 있습니다.

번역 브리지를 포함한 단계별 설정 안내: https://wonjoonseol-ws.github.io/subpair/ko/

## 카테고리
Chrome: 교육. Firefox: 언어 지원 ("사진, 음악 및 동영상"에도 맞음).

## 단일 목적 (Chrome)
언어 학습을 돕기 위해 동영상 플레이어(Netflix, Jellyfin)에서 두 언어의 자막을 동시에 보여 줍니다.

## 권한 사유 (Chrome)
- **storage**: 사용자의 설정과 프로필, 켜기/끄기 상태를 저장합니다.
- **scripting**: 사용자가 접근을 허용한 Jellyfin 서버에서만 Subpair를 실행합니다 (그 주소 하나에 콘텐츠 스크립트를 등록하고
  열려 있는 페이지에서 바로 시작합니다).
- **호스트 권한 http://127.0.0.1/\*, http://localhost/\***: 사용자가 자기 컴퓨터에서 실행하는 선택 프로그램인 번역 브리지에
  연결하기 위해서입니다. 확장 프로그램 워커는 다른 호스트에 연결하지 않습니다.
- **선택 호스트 권한 \*://\*/\***: Jellyfin은 어느 주소에나 직접 설치합니다. 설치할 때는 아무 권한도 받지 않으며, 사용자가 그
  서버 페이지에서 툴바 버튼을 누르거나 설정에서 추가할 때만 그 서버 하나에 대한 접근을 요청하고, 브라우저가 먼저 사용자에게
  묻습니다.
- **\*.netflix.com의 콘텐츠 스크립트**: Netflix 자막 트랙을 읽고 플레이어에 두 줄을 그리기 위해서입니다.
- **웹 접근 가능 리소스**: 콘텐츠 스크립트가 불러오는 확장 프로그램 자체 모듈과 일본어 사전입니다.
- **commands / action**: Subpair를 켜고 끄는 툴바 버튼과 단축키입니다.
- **원격 코드**: 없습니다. 모든 코드는 패키지에 들어 있습니다.

## 데이터 사용 (Chrome "개인정보 보호 관행" / AMO 데이터 수집)
- 수집: **웹사이트 콘텐츠**(재생 중인 영상의 자막 텍스트). 번역이 필요할 때만입니다.
- 전송 위치: 사용자 컴퓨터의 127.0.0.1에 있는 번역 브리지. 브리지는 선택 사항이며 사용자가 직접 실행합니다. 브리지는
  사용자가 설정한 번역 서비스(예: Anthropic 또는 OpenAI 호환 API)로 사용자 본인 계정으로 텍스트를 보낼 수 있습니다.
- Jellyfin에서는 완성된 번역을 영상이 재생되는 사용자 본인의 Jellyfin 서버에 그 작품의 자막 트랙으로도 올립니다(그 언어
  자막이 없는 작품만). 개발자에게는 아무것도 가지 않습니다.
- 수집하지 않음: 개인 정보, 건강, 금융, 인증 정보(Jellyfin 로그인 토큰은 같은 Jellyfin 서버를 호출할 때만 쓰고 다른 곳으로
  보내지 않습니다), 위치, 방문 기록, 사용자 활동.
- 확인 사항: 데이터를 판매하지 않고, 단일 목적과 무관한 용도로 사용하거나 전송하지 않으며, 신용도 판단이나 대출에 쓰지
  않습니다.
- Firefox 매니페스트: `data_collection_permissions.required = ["websiteContent"]`.
