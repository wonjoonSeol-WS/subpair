이미 즐겨 보는 작품으로 언어를 배우세요

Subpair는 Netflix와 내 Jellyfin 라이브러리에서 배우고 있는 언어와 내 언어, 두 가지 자막을 화면에 함께 띄웁니다. 작품에 내 언어 자막이 없으면 컴퓨터에서 실행하는 도우미 프로그램이 번역합니다.

Chrome, Edge, Brave, Firefox에서, 그리고 Windows, macOS, Linux에서 쓸 수 있습니다.

보면서 공부하는 데 필요한 모든 것

자막을 노트에 옮겨 적을 필요도, 영상을 멈추고 사전을 찾을 필요도 없습니다.

언제나 두 줄

위에는 배우고 있는 언어, 아래에는 내 언어. 트랙이 없을 때를 대비해 대체 언어도 지정할 수 있습니다.

자막이 없으면 번역

내 언어 자막이 없나요? Subpair가 내 컴퓨터에서 또는 AI로 주 자막을 번역하고, 그 번역을 기억합니다.

어느 줄이든 다시 듣기

키 하나로 이전 줄, 현재 줄, 다음 줄로 이동하고, 줄이 끝날 때마다 일시정지할 수 있습니다.

클릭할 수 있는 단어

일본어는 품사별로 색이 입혀집니다. 단어를 클릭하면 사전이나 플래시카드에 쓸 수 있도록 복사됩니다.

전체 대본

한 화의 모든 줄을 옆 패널에 보여 줍니다. 줄을 클릭하면 바로 그 위치로 이동합니다.

개인정보를 지키는 설계

계정도, 추적도 없습니다. 번역을 켜지 않는 한 어떤 데이터도 컴퓨터 밖으로 나가지 않습니다.

사용 방법

영상을 재생하면 Subpair가 바로 나타납니다. 키는 영상에서 벗어나지 않고 쓸 수 있습니다.

  • A 이전 줄
  • R 현재 줄 반복
  • D 다음 줄
  • Q 줄이 끝날 때마다 자동 일시정지
  • 클릭 단어 복사
  • Ctrl클릭 기본형 복사
  • Alt클릭 줄 전체 복사
  • AltShiftS Subpair 켜기/끄기

톱니바퀴 버튼으로 보고 있는 영상의 언어, 글자 크기, 위치, 번역을 바꿀 수 있습니다. 키는 설정에서 바꿀 수 있습니다.

Yomitan으로 단어 찾기

무료 사전 Yomitan과 함께 쓰세요.

Yomitan의 Clipboard monitor(클립보드 모니터)를 켜면 Subpair에서 클릭하는 단어를 바로 찾아 줍니다. 또는 단어 위에서 Shift를 누르고 있으면 Yomitan 팝업이 뜹니다.

세 단계로 시작하기

5분 정도면 됩니다. 계정은 필요 없습니다.

언어 고르기

설정 페이지가 자동으로 열립니다. 배우고 있는 언어와 내 언어를 고르세요.

재생하기

Netflix나 내 Jellyfin 서버를 열고 작품을 재생하세요. Jellyfin에서는 "이 서버에서 Subpair를 사용할까요?"를 한 번 클릭합니다.

원하는 방식으로 번역

작품에 내 언어 자막이 없으면 컴퓨터에서 실행하는 도우미 프로그램(선택 사항)이 번역합니다. 나에게 맞는 방법을 고르세요.

오프라인

ezTrans

Windows에서 ezTrans XP로 일본어를 한국어로, 영상보다 몇 줄 앞서 번역합니다.

내 Claude 요금제

Claude Code

이미 쓰고 있는 Claude 구독으로 모든 언어쌍을 번역합니다.

한 화에 약 $0.01

AI API

Anthropic, OpenAI, Gemini, DeepSeek 등을 내 키로 사용합니다.

무료, 개인정보 보호

로컬 AI

내 컴퓨터에서 실행하는 Ollama나 LM Studio를 사용합니다.

모든 번역은 저장되므로 한 번 번역한 작품은 바로 불러옵니다. 번역의 동작 방식

선택 사항, Bazarr를 쓰는 Jellyfin용

자막 파일의 싱크가 맞지 않나요? subsync-repair를 써 보세요

Bazarr가 내려받는 모든 자막을 영상과 비교해 검사하는 동반 도구입니다. 일부 구간에서 어긋나는 자막은 고치고, 다른 화용으로 만든 자막은 거부해 Bazarr가 더 나은 자막을 찾을 수 있게 합니다.
