좋아하는 작품으로 외국어 공부

Netflix와 내 Jellyfin에서 배우는 언어와 모국어 자막을 한 화면에 함께 띄워요. 모국어 자막이 없는 작품은 PC에서 돌아가는 번역 도우미가 번역해 줘요.

보면서 바로 공부하세요

자막을 받아 적거나, 영상을 멈추고 사전을 뒤질 필요가 없어요.

두 줄 자막

위에는 배우는 언어, 아래에는 모국어. 자막이 없을 때 대신 쓸 언어도 정해 둘 수 있어요.

자막이 없으면 번역

모국어 자막이 없어도 괜찮아요. PC나 AI로 원어 자막을 번역하고, 한 번 번역한 건 저장해 둬요. Jellyfin에서는 보는 동안 다음 화를 미리 번역하고, 시즌 전체도 클릭 한 번이면 돼요.

한 줄씩 다시 듣기

키 하나로 이전 줄, 다시 듣기, 다음 줄. 대사가 끝날 때마다 자동으로 멈추게 할 수도 있어요.

클릭하면 복사되는 단어

일본어는 품사마다 색을 달리해 보여 줘요. 단어를 클릭하면 사전이나 단어장에 넣기 좋게 복사돼요.

대사 목록

한 화의 대사를 옆 패널에 모두 보여 줘요. 대사를 누르면 그 장면으로 바로 넘어가요.

개인정보 걱정 없이

가입도 추적도 없어요. 번역을 켜지 않으면 어떤 데이터도 PC 밖으로 나가지 않아요.

사용법

영상을 틀면 Subpair가 바로 떠요. 보던 그대로 키만 누르면 돼요.

  • A 이전 줄
  • R 다시 듣기
  • D 다음 줄
  • Q 대사마다 자동 멈춤
  • 클릭 단어 복사
  • Ctrl클릭 기본형 복사
  • Alt클릭 대사 전체 복사
  • AltShiftS Subpair 켜기/끄기

톱니바퀴 버튼으로 지금 보는 영상의 언어, 글자 크기, 위치, 번역을 바꿀 수 있어요. 단축키는 설정에서 바꿀 수 있어요.

Yomitan으로 단어 찾기

무료 사전 확장 프로그램 Yomitan과 같이 쓰면 더 편해요.

Yomitan의 Clipboard monitor를 켜 두면 Subpair에서 클릭한 단어를 바로 찾아 줘요. 단어 위에서 Shift를 누르면 Yomitan 팝업으로 볼 수도 있어요.

3단계로 시작하기

5분이면 충분해요. 가입은 필요 없어요.

언어 고르기

설정 화면이 저절로 열려요. 배우는 언어와 모국어를 고르면 끝이에요.

재생하기

Netflix나 내 Jellyfin에서 작품을 틀어 보세요. Jellyfin에서는 처음 한 번 툴바의 Subpair 버튼을 눌러 그 서버에서 켜 주세요.

번역 방식은 골라서

모국어 자막이 없는 작품은 PC에서 돌아가는 번역 도우미(선택 사항)가 번역해요. 편한 방식을 고르세요.

오프라인

ezTrans

Windows에서 ezTrans XP로 일본어를 한국어로. 영상보다 몇 줄 앞서 번역해요.

Claude 구독으로

Claude Code

쓰고 있는 Claude 구독으로 어떤 언어든 번역해요.

한 화에 약 10원

AI API

Anthropic, OpenAI, Gemini, DeepSeek 등을 내 API 키로 써요.

무료, 내 PC에서

로컬 AI

Ollama나 LM Studio로 내 컴퓨터 안에서 번역해요.

번역은 모두 저장돼서, 한 번 번역한 작품은 바로 불러와요. 번역 시작하는 법

선택 사항: 내 영상 라이브러리용

자막 싱크가 안 맞나요? subsync-repair

내 서버의 자막 파일을 영상과 하나하나 맞춰 보는 도구예요. 일부 구간만 어긋난 자막은 고치고, 다른 화의 자막은 건드리지 않아요. 폴더나 파일을 골라 직접 돌려도 되고, Bazarr가 자막을 받을 때마다 알아서 돌게 할 수도 있어요.
