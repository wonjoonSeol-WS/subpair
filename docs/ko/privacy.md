# 개인정보 처리방침

최종 수정일: 2026-10-20

Subpair는 Netflix와 Jellyfin 서버에서 자막 두 줄을 보여 주는 브라우저 확장 프로그램입니다. Subpair에는 자체 서버가
없습니다. 개발자에게는 아무것도 전송되지 않으며, 분석, 광고, 그 밖의 어떤 목적으로도 아무것도 수집하지 않습니다.

## Subpair가 읽는 것

- 재생 중인 작품의 **자막 트랙**: Netflix에서는 Netflix 플레이어가 불러오는 자막 목록에서 읽고, Jellyfin 서버에서는
  해당 항목에 대한 그 서버의 자막 트랙에서 읽습니다.
- **Jellyfin에서만**, Jellyfin 웹 클라이언트가 페이지의 로컬 스토리지에 보관하는 정보인 로그인 토큰, 사용자 ID,
  서버 주소, 기기 ID를 읽습니다. Subpair는 이 정보를 바로 그 Jellyfin 서버에 이 기기에서 어떤 항목이 재생 중인지
  묻고, 그 항목의 상세 정보와 자막 트랙을 요청하고, 끝난 번역을 그 항목에 추가하는(아래 참고) 데에만 사용합니다.
- Subpair는 사용자가 사용하도록 설정한 Jellyfin 서버에서만 동작합니다. 서버 주소가 localhost나 127.0.0.1이 아니면
  브라우저가 먼저 Subpair에 그 서버 접근을 허용할지 묻습니다. 이 허용은 설정(*Jellyfin 서버*)이나 브라우저의 확장 프로그램 설정에서
  취소할 수 있습니다.

## Subpair가 브라우저에 저장하는 것

- **설정과 프로필**(언어, 레이아웃, 단축키, 번역기 선택): 브라우저의 확장 프로그램 동기화 저장소에 저장합니다.
  브라우저에 로그인되어 있으면 브라우저가 이를 브라우저 계정에 동기화할 수 있습니다. 동기화 저장소에 담기에 너무
  크면 이 컴퓨터에만 남습니다.
- **이 컴퓨터에만**: 켜기/끄기 스위치, 사용하도록 설정한 Jellyfin 서버, 전체 화면에서 대본 패널을 표시할지 여부,
  "대신 주 자막을 번역"을 선택한 작품, Subpair가 어떤 번역을 어떤 Jellyfin 항목에 추가했는지.

확장 프로그램을 제거하면 이 컴퓨터에 저장된 데이터가 제거됩니다. 브라우저가 브라우저 계정에 동기화한 설정은
브라우저의 동기화 서비스가 확장 프로그램 데이터를 처리하는 방식에 따라 유지되거나 제거됩니다.

## Subpair가 보내는 것과 받는 곳

- 두 번째 자막을 번역해야 하고 선택 사항인 번역 브리지를 사용하는 경우가 아니면, **아무것도** 보내지 않습니다.
- **그 경우:** 작품의 자막 텍스트가 `127.0.0.1` / `localhost`의 브리지로 전송됩니다. 브리지는 사용자가 자신의
  컴퓨터에서 직접 실행하는 별도의 프로그램입니다. Subpair는 번역을 위해 다른 어떤 주소와도 통신하지 않습니다.
- **브리지가 이 텍스트를 어떻게 처리하는지**는 설정 방법에 따라 다릅니다.
  - **ezTrans:** 사용자의 컴퓨터에서 번역됩니다.
  - **Claude (`claude -p`):** 사용자 본인의 Claude Code 로그인을 통해 Anthropic으로 전송됩니다.
  - **Anthropic API 또는 OpenAI 호환 API:** 사용자 본인의 API 키로 해당 제공자에게 전송되거나, 사용자가 직접
    운영하는 모델 서버로 전송됩니다.

  이러한 경우 제공자는 사용자 본인의 계정으로, 제공자 자체의 약관에 따라 자막 텍스트를 받습니다. 브리지는 끝난
  번역을 사용자의 컴퓨터에 저장합니다.
- **사용자 본인의 Jellyfin 서버로:** Jellyfin 작품의 번역이 끝나면, 그 작품이 있는 서버에 자막 트랙으로 추가해 다른
  Jellyfin 앱에서도 보이게 합니다. 작품에 그 언어의 자막이 없을 때만 추가하며, 다른 서버로는 보내지 않습니다.

## Subpair가 절대 하지 않는 것

- 분석, 원격 측정, 충돌 보고, 광고가 없습니다.
- 개발자가 운영하는 서버가 없습니다. 어떤 데이터도 개발자나 그 밖의 누구에게도 판매, 공유, 전송되지 않습니다.
- 원격 코드가 없습니다. Subpair가 실행하는 모든 것은 확장 프로그램 패키지의 일부입니다.

## Firefox 데이터 선언

Firefox는 확장 프로그램에 전송하는 데이터를 선언하도록 요청합니다. 페이지의 자막 텍스트가 로컬 번역 브리지로 가기
위해 확장 프로그램 밖으로 나갈 수 있으므로, Subpair는 **웹사이트 콘텐츠**(`websiteContent`)를 선언합니다.

## 이 웹사이트

이 웹사이트는(확장 프로그램이 아니라) 오픈소스 방문 집계 도구인 [GoatCounter](https://www.goatcounter.com/)로 방문
수를 셉니다. 페이지별 방문 수 같은 합계만 남기고 누가 방문했는지는 남기지 않으며, IP 주소나 브라우저 정보는 저장하지
않습니다([GoatCounter의 집계 방식](https://www.goatcounter.com/help/sessions)).
