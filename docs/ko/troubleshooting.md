# 문제 해결

## 아무것도 표시되지 않음

- **아직 언어를 고르지 않음**: 오른쪽 위에 *Subpair: 언어를 선택하세요* 알림이 나타납니다. 설정을 열고 주 자막
  언어를 고르세요.
- **Subpair가 꺼져 있음**: 툴바 버튼에 *끔*이 표시됩니다. 버튼을 클릭하거나 Alt+Shift+S를 누르세요.
- **Jellyfin 서버를 아직 허용하지 않음**: 오른쪽 위의 *이 서버에서 Subpair를 사용할까요?* 알림을 클릭하세요.
- **설치나 업데이트 직후의 Netflix**: Netflix 탭을 한 번 새로고침하세요.
- **영상에 주 자막 언어의 텍스트 자막이 없음**: 이미지 자막(PGS, VobSub)은 읽을 수 없습니다. 다른 주 자막 언어를
  고르거나, Jellyfin 항목에 텍스트 자막 파일을 추가하세요.

## 두 번째 자막이 없거나 다른 언어로 나옴

두 번째 자막에는 두 번째 자막 언어 중 트랙이 있는 첫 번째 언어가 쓰입니다. 트랙이 있는 언어가 없으면 주 자막을
번역하며, 이때 브리지가 필요합니다. 톱니바퀴 메뉴의 **두 번째 자막** 항목에서 무엇이 왜 표시되는지 알 수 있습니다.
흔한 원인은 다음과 같습니다.

- *번역 브리지가 실행 중이 아닙니다*: 브리지(`npm run bridge`)나 시작 작업을 실행하세요.
- *번역할 수 있는 번역기가 없습니다*: 브리지의 `/health` 페이지에서 어떤 번역기가 설정되어 있는지 확인할 수
  있습니다.
- 설정의 브리지 주소가 브리지의 포트와 맞지 않습니다.

## 자막 싱크가 맞지 않음

톱니바퀴 메뉴의 **자막 싱크**에서 이 영상의 주 자막 전체나 두 번째 자막 전체를 앞당기거나 늦출 수 있습니다. 자막 파일의 일부
구간만 어긋난다면 파일 자체를 고쳐야 합니다. 내려받은 파일은 다른 릴리스에 맞춰져 있거나, 아예 다른 화의 자막일
수도 있습니다. Jellyfin 라이브러리라면 별도 프로젝트인 subsync-repair가 영상 자체의 트랙을 기준으로 자막 파일을
검사하고 고쳐 줍니다. 두 번째 자막 트랙이 이상하다면 **두 번째 자막**, **대신 주 자막을 번역**으로 그 트랙을
번역으로 바꿀 수 있습니다.

## 브리지가 시작되지 않음

- `cannot listen on 127.0.0.1:8765`: 그 포트에서 이미 다른 브리지가 실행 중입니다. 그 브리지를 멈추거나
  `BRIDGE_PORT`로 다른 포트를 지정하세요(설정의 주소도 같게 맞춥니다).
- `unknown setting`: `bridge/config.json`의 설정 이름에 오타가 있습니다. `bridge/config.defaults.json`과 비교하세요.
- Node.js가 21보다 오래된 버전: 최신 버전을 설치하세요.

## 브리지의 오류 메시지

플레이어는 브리지의 오류를 사용자의 언어로 보여 줍니다. 직접 조치해야 하는 메시지는 다음과 같습니다.

| 메시지 | 해결 방법 |
|---|---|
| claude 명령이 실행되지 않았습니다 | Claude Code를 설치하고 `claude`를 한 번 실행해 로그인하거나, `claude.command`를 설정하세요 |
| Anthropic API 키가 없습니다 | `ANTHROPIC_API_KEY` 또는 `api.key`를 설정한 다음 브리지를 다시 시작하세요 |
| OpenAI 호환 번역기가 설정되지 않았습니다 | `openai.baseUrl`, `openai.model`을 설정하고, 호스팅 서비스라면 그 키도 설정하세요 |
| ezTrans XP를 찾지 못했습니다 | `eztrans.dir`을 ezTrans XP 폴더로 설정하세요(Windows 전용) |
| ... cmd.exe로 안전하게 실행할 수 없습니다 | `claude.command`를 `.cmd`가 아닌 `.exe`로 지정하세요 |
| 허용되지 않은 출처 | `bridge/config.json`의 `allowedOrigins`에 지금 쓰는 Subpair가 들어 있지 않습니다. 현재 ID를 추가한 다음(확장 프로그램을 다른 폴더에서 불러오면 ID가 바뀝니다) 브리지를 다시 시작하세요 |

## 로그 위치

- 직접 실행한 브리지: 그 터미널에 출력됩니다.
- Windows 시작 작업: `%LOCALAPPDATA%\subpair\bridge.log` 또는 `-Log`로 지정한 파일.
- 확장 프로그램: Netflix나 Jellyfin 탭의 브라우저 개발자 콘솔(줄이 `[Subpair]`로 시작합니다).
