# トラブルシューティング

## 何も表示されない

- **まだ言語を選んでいない**：右上に「Subpair: 言語を選んでください」という通知が表示されます。設定を開いて、メイン字幕の言語を選んでください。
- **Subpairがオフになっている**：ツールバーボタンに「OFF」と表示されます。ボタンをクリックするか、Alt+Shift+Sを押してください。
- **Jellyfinサーバーをまだ許可していない**：右上の「このサーバーでSubpairを使いますか?」をクリックしてください。
- **インストールまたは更新した直後のNetflix**：Netflixのタブを一度再読み込みしてください。
- **動画にメイン字幕の言語のテキスト字幕がない**：画像字幕（PGS、VobSub）は読み取れません。ほかのメイン字幕の言語を選ぶか、Jellyfinのアイテムにテキスト字幕ファイルを追加してください。

## 2行目の字幕が表示されない、または別の言語になる

2行目の字幕には、2行目の字幕の言語のうち、トラックがある最初の言語が使われます。どの言語にもトラックがない場合はメイン字幕を翻訳するため、ブリッジが必要です。歯車メニューの**2行目の字幕**の行に、何がなぜ表示されているかが示されます。よくある原因は次のとおりです。

- 「翻訳ブリッジが起動していません」：ブリッジ（`npm run bridge`）またはスタートアップタスクを起動してください。
- 「翻訳できる翻訳エンジンがありません」：ブリッジの`/health`ページで、どの翻訳エンジンが設定済みかを確認できます。
- 設定のブリッジのアドレスが、ブリッジのポートと一致していない。

## 字幕のタイミングがずれる

歯車メニューの**字幕のタイミング**で、この動画のメイン字幕全体、または2行目の字幕全体を早めたり遅らせたりできます。字幕ファイルの一部だけがずれている場合は、ファイル自体の修正が必要です。ダウンロードしたファイルが別のリリースに合わせてあったり、そもそも別の話数のものだったりすることがあります。Jellyfinのライブラリなら、別プロジェクトのsubsync-repairが、動画自体のトラックをもとに字幕ファイルをチェックして修正します。2行目のトラックがおかしい場合は、**2行目の字幕**、**代わりにメイン字幕を翻訳**で翻訳に置き換えられます。

## ブリッジが起動しない

- `cannot listen on 127.0.0.1:8765`：そのポートですでに別のブリッジが動いています。それを止めるか、`BRIDGE_PORT`で別のポートを設定してください（設定のアドレスも同じにします）。
- `unknown setting`：`bridge/config.json`の設定名にタイプミスがあります。`bridge/config.defaults.json`と見比べてください。
- Node.jsが21より古い：最新のバージョンをインストールしてください。

## ブリッジのエラーメッセージ

プレーヤーは、ブリッジのエラーをお使いの言語で表示します。対応が必要なものは次のとおりです。

| メッセージ | 対処法 |
|---|---|
| claudeコマンドが実行できませんでした | Claude Codeをインストールして`claude`を一度実行してログインするか、`claude.command`を設定してください |
| Anthropic APIキーがありません | `ANTHROPIC_API_KEY`または`api.key`を設定し、ブリッジを再起動してください |
| OpenAI互換の翻訳エンジンが設定されていません | `openai.baseUrl`と`openai.model`を設定し、ホスティングサービスならそのキーも設定してください |
| ezTrans XPが見つかりません | `eztrans.dir`にezTrans XPのフォルダーを設定してください（Windowsのみ） |
| ...をcmd.exeで安全に実行できません | `claude.command`を`.cmd`ではなく`.exe`に向けてください |
| 許可されていないオリジン | `bridge/config.json`の`allowedOrigins`に、いま使っているSubpairが含まれていません。現在のIDを追加して（拡張機能を別のフォルダーから読み込むとIDが変わります）、ブリッジを再起動してください |

## ログの場所

- 手動で起動したブリッジ：そのターミナルに出力されます。
- Windowsのスタートアップタスク：`%LOCALAPPDATA%\subpair\bridge.log`、または`-Log`で指定したファイル。
- 拡張機能：NetflixまたはJellyfinのタブで開いたブラウザーの開発者コンソール（行は`[Subpair]`で始まります）。
