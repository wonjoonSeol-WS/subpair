# 字幕を翻訳する

自分の言語の字幕がない作品でも大丈夫です。Subpairが元の字幕を翻訳して、2行目に表示します。翻訳はパソコン上の小さな
**補助プログラム**が担当し、一度翻訳した作品は保存されるので、次からはすぐに表示されます。Jellyfinでは、1話の翻訳が終わると次の話も先に翻訳しておきます。

## どの翻訳エンジンを使う？

| 翻訳エンジン | こんな方に | 費用 |
|---|---|---|
| **ezTrans** | 日本語の作品を韓国語で見るWindowsユーザー（ezTrans XPが必要） | 無料、オフライン |
| **Claude** | Claudeを契約している方。どの言語でも翻訳できます | プランに含まれる |
| **AI API** | Anthropic、OpenAI、GeminiなどのAPIキーをお持ちの方 | 1話あたり約1〜2円 |
| **ローカルAI** | OllamaやLM Studioを使っている方 | 無料 |

選ばなくても使えます。既定の**自動**が、準備できている翻訳エンジンを選びます。日本語から韓国語ならezTransが優先です。

## ezTransですぐに始める（Windows）

1. **ezTrans XPをインストールする**：インストール済みなら飛ばしてください。インストール先は補助プログラムが自動で見つけます。
2. **Node.jsをインストールする**：[nodejs.org](https://nodejs.org/ja)から**LTS**版をダウンロードし、既定の設定のままインストールします。
3. **Subpairをダウンロードする**：[ZIPファイルをダウンロード](https://github.com/wonjoonSeol-WS/subpair/archive/refs/heads/main.zip)して、ドキュメントフォルダーなど好きな場所に展開します。
4. **補助プログラムを起動する**：展開したフォルダーの`start-bridge.cmd`をダブルクリックします。黒いウィンドウに`ezTrans XP in ...`と表示されれば準備完了です。視聴中はこのウィンドウを開いたままにしてください。
5. **作品を再生する**：日本語字幕だけの作品を再生すると、2行目に韓国語の翻訳が表示されます。

インターネットから入手したファイルなので、Windowsがセキュリティの警告を出すことがあります。その場合は**実行**を押してください。青いウィンドウが表示されたときは、**詳細情報**を押してから**実行**を押します。

### Windowsの起動時に自動で起動する

展開したフォルダーの`scripts\windows`にある`autostart-on.cmd`をダブルクリックします。Windowsにサインインするたびに補助プログラムがウィンドウなしで起動するようになり、`start-bridge.cmd`を実行する必要はなくなります。元に戻すには、同じフォルダーの`autostart-off.cmd`をダブルクリックします。

### うまくいかないとき

- **黒いウィンドウに`ezTrans XP not found`と表示される**：ezTrans XPが既定の場所にインストールされているか確認してください。別の場所にある場合は、[READMEのブリッジの設定](https://github.com/wonjoonSeol-WS/subpair/blob/main/README.ja.md#ブリッジの設定)の方法でフォルダーを指定できます。
- **`Node.js is not installed`と表示される**：手順2のNode.jsをインストールしてから、もう一度ダブルクリックしてください。
- **翻訳が表示されない**：補助プログラムのウィンドウが開いているか確認してください。ウィンドウを閉じると翻訳も止まります。

## ほかの翻訳エンジンを使う

補助プログラムの起動方法（上の手順2〜4）は同じです。翻訳エンジンを準備してから、動画の歯車メニューの**翻訳エンジン**で選んでください。

- **Claude**：[Claude Code](https://claude.com/claude-code)をインストールし、一度起動してサインインすれば完了です。
- **AI API、ローカルAI**：APIキーやアドレスを設定ファイルに書く必要があります。[READMEのブリッジの設定](https://github.com/wonjoonSeol-WS/subpair/blob/main/README.ja.md#ブリッジの設定)をご覧ください。

補助プログラムはmacOSとLinuxでも使えます（ezTransはWindows専用）。起動方法はREADMEにあります。

## 費用

AI APIでアニメ1話（約300行）を翻訳すると**約1〜2円**、12話のシーズン全体で**約10〜20円**です。既定のモデルであるClaude Haiku 5.5の料金で計算した目安です（2026年10月、1ドル約158円で換算）。一度翻訳した行に再び費用はかかりません。ezTransとローカルAIは無料で、Claudeはプランの利用量に含まれます。

## 歯車メニューでできること

- **翻訳エンジン**：使う翻訳エンジンと、翻訳するタイミング（自動、リアルタイムで数行先まで、今すぐ作品全体）を選びます。
- **この作品をもう一度翻訳**：保存された翻訳が気に入らないときに、新しく翻訳し直します（2回クリック）。
- **シーズン全体を翻訳**（Jellyfin）：1話ずつ順に、前もって翻訳しておきます。
- **代わりにメイン字幕を翻訳**：作品に入っている自分の言語の字幕がおかしいときや、タイミングが合わないときに、その字幕の代わりに翻訳を使います。作品ごとに記憶します。

翻訳はこのパソコンにだけ保存されます。テレビやスマートフォンのJellyfinアプリには表示されません。
