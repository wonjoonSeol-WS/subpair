いつも見ている作品で語学を学びましょう

Subpairは、Netflixとご自身のJellyfinライブラリで、学習中の言語と自分の言語の2つの字幕を同時に画面に表示します。作品に自分の言語の字幕がないときは、パソコン上の補助プログラムが翻訳します。

字幕をノートに書き写す必要も、動画を止めて辞書を引く必要もありません。

いつでも2行

上に学習中の言語、下に自分の言語。トラックがないときのための予備の言語も指定できます。

字幕がなければ翻訳

自分の言語の字幕がありませんか？Subpairがパソコン上で、またはAIでメイン字幕を翻訳し、その翻訳を記憶します。Jellyfinでは視聴中に次の話を先に翻訳し、シーズン全体もワンクリックで翻訳できます。

どの行でもリピート

キー1つで前の行、同じ行、次の行に移動でき、各行の終わりで一時停止することもできます。

クリックできる単語

日本語は品詞ごとに色分けされます。単語をクリックすると、辞書や単語カードで使えるようにコピーされます。

全文トランスクリプト

エピソードのすべての行をサイドパネルに表示します。行をクリックすると、その位置にすぐ移動します。

プライバシー重視の設計

アカウント不要、トラッキングなし。翻訳をオンにしない限り、データがパソコンの外に出ることはありません。

使い方

動画を再生すれば、Subpairがすぐに使えます。キー操作は動画を見たまま使えます。

  • A 前の行
  • R この行をリピート
  • D 次の行
  • Q 各行の終わりで自動一時停止
  • クリック 単語をコピー
  • Ctrlクリック 辞書形をコピー
  • Altクリック 行全体をコピー
  • AltShiftS Subpairのオン/オフ

歯車ボタンで、視聴中の動画の言語、文字サイズ、位置、翻訳を変更できます。キーは設定で変更できます。

Yomitanで単語を調べる

無料の辞書Yomitanと組み合わせて使えます。

YomitanのClipboard monitor（クリップボードの監視）をオンにすると、Subpairでクリックした単語をすぐに調べられます。または、単語の上でShiftを押し続けると、Yomitanのポップアップが表示されます。

言語を選ぶ

設定ページが自動的に開きます。学習中の言語と自分の言語を選んでください。

再生する

Netflixまたはご自身のJellyfinサーバーを開いて、作品を再生してください。Jellyfinでは、最初に一度ツールバーのSubpairボタンを押して、そのサーバーで有効にします。

翻訳は好きな方法で

作品に自分の言語の字幕がないときは、パソコン上の補助プログラム（任意）が翻訳します。自分に合った方法を選んでください。

オフライン

ezTrans

WindowsでezTrans XPを使い、日本語を韓国語に、動画の数行先まで翻訳します。

ご自身のClaudeプラン

Claude Code

すでにお持ちのClaudeのサブスクリプションで、あらゆる言語の組み合わせを翻訳します。

1話あたり約1〜2円

AI API

Anthropic、OpenAI、Gemini、DeepSeekなどを、ご自身のキーで使えます。

無料、プライベート

ローカルAI

ご自身のパソコンで動くOllamaやLM Studioを使います。

翻訳はすべて保存されるため、一度翻訳した作品はすぐに読み込まれます。翻訳の始め方

任意、自分の動画ライブラリ向け

字幕ファイルのタイミングがずれていませんか？subsync-repairを試してみてください

サーバーにある字幕ファイルを、動画と1つずつ照合する関連ツールです。一部だけずれている字幕を修正し、別の話数用に作られた字幕には手を加えません。フォルダーやファイルを指定して実行することも、Bazarrが字幕をダウンロードするたびに自動で実行させることもできます。
